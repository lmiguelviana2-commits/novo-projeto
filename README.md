# novo-projeto

Este projeto foi criado com [Criativa](https://criativalab.app) — a plataforma brasileira que gera aplicações a partir de uma descrição em português.

## Como editar este código?

**Usando a Criativa**

Abra o projeto na Criativa e continue pedindo alterações pelo chat. As mudanças são enviadas automaticamente para este repositório.

**Usando seu editor local**

Você também pode clonar este repositório e editar os arquivos diretamente. É necessário ter o [Node.js](https://nodejs.org) instalado.

```sh
# Clone o repositório
git clone <URL_DO_REPOSITORIO>

# Entre na pasta do projeto
cd novo-projeto

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Quais tecnologias este projeto usa?

- [Vite](https://vitejs.dev)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com) (via CDN)

## Como publicar este projeto?

Pela Criativa: abra o projeto e clique em "Publicar". Você também pode fazer o build (`npm run build`) e hospedar a pasta `dist` em qualquer serviço de hospedagem de sites estáticos.
